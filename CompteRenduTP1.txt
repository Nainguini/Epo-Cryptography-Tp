Rappel du projet:
		On construit un module Python coffre.py qui chiffre un fichier avec un mot de passe. Le fichier chiffré a le format suivant :
		Identifiant de format CFR1 	4 octets 
		Paramètres Argon2id (t, m, p)  	12 octets
		Sel 					16 octets 
		Nonce 				12 octets 
		Chiffré + étiquette 			variable  
		Les 44 premiers octets (l’en-tête) et le nom du fichier forment les données associées : ils sont authentifiés sans être chiffrés

--------------------------	Questions de réflexion	----------------------------------------			

1#
Le sel est une information importante qui rentre ds le chiffrement de la donnée. 
Il est essentiel pour déchiffrer la données chiffrée puisque c'est le meme sel qui sera utilisé lors du déchiffrement. 

Dans le cas des mot de passe, 
il est stocké en clair par qu'il n'est pas un secret, c'est le mot de passe qui est secret. Son objectif est de produire une empreinte unique qui resistera a une attaque brute force.

Quand bien meme il ne soit pas entouré de mystère comme le mot de passe, publier le sel est dangereux car il intervient dans le déchiffrement du mot de passe. En règle generale toutes informations, ausi bénigne soit elle est importante lorsque on veut faire une attaque.

2#
C'est une question de probalité. tirer un nonce sur 96bits soit 12 octets permet d'aggrandir la probabilité d'apparition unique du nonce lors du traitement de plusieurs données.

3#
Les données associées ne sont pas predefinis statutairement. Comme leur nom l'indique ce sont des informations supplementaires qui augmentent la sécurite du chiffrement. De ca fait on aurait pu choisir les metadata sans inclure le nom du fichier. 
Seulement le nom de fichier est tout aussi important pour eviter certains types d'attaques; renommer un fichier peut induire en erreur le destinataire 

4#
L'entete est authentifié pour eviter certaines formes d'attaques

5# Comme evoqué précedemment toutes informations est bonne pour etre utilisée dans une attaque. La confidentitialité sur l'algorithm utilisé meme est une forme de sécurité afin d'allourdir la tâche de l'attaquant. Si on affiche beaucoup d'informations en cas d'erreur il saura quelle algorithme nous avons utilisé.
